# Juno — Meeting Co-pilot

A private, on-device meeting co-pilot for macOS and Windows: live transcription,
real-time assist, and notes for your calls. Your meetings stay on your machine.

This repository is for **bug reports and feature requests**. The app source is
not public.

## Report a bug or request a feature

Open an issue: https://github.com/chiragd03/juno-meeting-copilot/issues/new/choose

For bugs, please attach a **debug bundle** so it can be diagnosed quickly:
in Juno, go to **Settings → Help & feedback → Export debug bundle**. The bundle
contains app logs and system info only — it does **not** include your meetings,
transcripts, or API keys.
